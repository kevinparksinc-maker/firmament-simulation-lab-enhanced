# Firmament Lab (Android)

Firmament Lab is an Android application built with Kotlin and Jetpack Compose that ports the Firmament Simulation Lab sports market monitor and astrological simulation engine.

## Features
- **Sports Market Monitor**: Browse scheduled games across MLB, NFL, and NBA with real-time sportsbook moneyline favorites and venue details.
- **Simulation Runner**: Run simulation fixtures comparing God View (permanent ancient background) and AgentView (event-local topography).
- **Simulation Result & Audit**: Detailed Game Brief, synthesized winner, convergence metrics, planetary placements table, and frame layer audits (HIT/MISS/TIE).
- **AI Research Assistant**: Interactive chat interface to explore calculation methods and audit transparency.

## Architecture
- **Language**: Kotlin
- **UI**: Jetpack Compose (Material Design 3)
- **Architecture**: MVVM with ViewModel and StateFlow
